Choose what to clear from the loop grid. Clear cells removes the painted pattern blocks but keeps the pattern rows and their BPM settings. Clear rows and cells removes the pattern rows from the loop as well. This never deletes patterns from the workspace.

Custom Drum Kit / Samples (.WAV, .MP3, .OGG)

All 23 tracks use built-in procedural Web Audio synthesis by default. Importing a ZIP replaces the grid with one row per audio file and clears the active pattern. Use Assign File to replace a sample, Use Synth / Remove on a row to delete just that sample, or unload every sample at once. Removals are undoable. Samples are saved inside the workspace file.

Import Drum Kit (.zip)

Reads every WAV/MP3/OGG inside the ZIP, including subfolders. Type a free-form name for each file (for example snare 1 or tom grave); each file becomes its own grid row and duplicate names get a suffix. The import clears the active pattern; selecting a factory pattern later restores any missing rows with the built-in synth.

ZeeOne Drum Machine — Help & Shortcuts

• Keyboard Shortcuts: Press Space to Play/Stop playback. Press C to clear active steps on the current pattern.

• Hide Tracks vs Clear All: Hide Tracks hides all drum rows on the right panel so you can build a minimal kit from scratch. Clear All erases the active notes on the current pattern. Neither removes imported samples.

• New Workspace: The first toolbar button, New, starts either a blank grid (no visible tracks) or the 23-track default synth kit. The File menu has the same action.

• Pattern Groups & Workspace: Collapse/expand or hide entire pattern groups in the left panel; the eye button under Patterns shows or hides the hidden groups. Click Save to export your entire Workspace (groups, patterns, visible tracks, and BPMs) to a .json file.

• Export Formats: Export Active Pattern and Export Loop ask for WAV, M4A or MP3. WAV is instant; M4A/AAC and MP3 are encoded locally in real time and are accepted by WhatsApp Web. The Save dialog then asks for the folder and file name, with the suggested name based on the pattern or loop settings.

• Time Signature: Choose one of the fixed presets: 2/4, 3/4, 4/4, 5/4, 6/4, 8/4, or 12/4.

• Hidden Tracks: Selecting a pattern with notes on hidden tracks asks whether to restore them or keep them as they are. Hidden tracks are silent in playback and exports. The Tracks dialog previews a local draft: checkboxes change only that draft until you press Apply; Cancel discards it. Use ▶ to audition any piece.

• Volume: Master Volume sits in the top toolbar; each row in the Drum Grid has its own volume slider. Both are saved with the workspace.

• Loop Arrangement: The bottom list plays one pattern per row, in order, when Loop Mode is on. Choose a pattern and click + Pattern to append it; drag rows to reorder them, use ✕ to remove a row, and Export Loop renders one full cycle in the format you choose. Each pattern lasts its natural number of beats at the loop BPM.

• Collapsible Panels: The Patterns title stays on the left and its chevron sits at the far right of that bar; the top-bar chevron sits just after the workspace status; the bottom loop panel has its own chevron. Each collapses into a narrow rail and expands again; none of these visual states are saved in the workspace.

• Resizable Panels: Drag the divider between Patterns and Drum Grid to change the sidebar width, or the divider above Loop Arrangement to change its height. Double-click a divider to reset it; arrow keys work when it is focused. Like collapses, sizes are visual only and are not saved.

• Reorder Rows: Drag a Drum Grid row by its grip (⠿) to place it before or after another row. The new kit order is saved with the workspace and is restored when you reopen the file.

• Removing Samples: In Drum Kit / Samples, use Use Synth / Remove on one row or Unload All Samples for the whole kit. The File menu has the same bulk action. Every removal offers Undo.
