# Bundled fonts

The application uses the same font families as the original single-file version,
bundled locally so it can run without a network connection.

| Family | Weights | Source |
| --- | --- | --- |
| Inter | 400–700 (variable) | https://fonts.google.com/specimen/Inter |
| JetBrains Mono | 500–700 (variable) | https://fonts.google.com/specimen/JetBrains+Mono |
| Orbitron | 700–900 (variable) | https://fonts.google.com/specimen/Orbitron |
| Rajdhani | 600, 700 | https://fonts.google.com/specimen/Rajdhani |

Files were downloaded from `fonts.gstatic.com` through the Google Fonts CSS API.
All four families are distributed under the SIL Open Font License (OFL).
See the individual font project pages for the full license text and attribution.
